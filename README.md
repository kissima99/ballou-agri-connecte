# Ballou Agri Connect

Plateforme d'échange agricole entre Ballou et Dakar.

## Dépôt GitHub
Cette application est liée au dépôt GitHub : [kissima99/ballou-agri-connecte](https://github.com/kissima99/ballou-agri-connecte)

## Fonctionnalités
- **Vente de produits locaux** : De Ballou vers Dakar (Riz, Oignons, Maïs, etc.).
- **Achat de produits de Dakar** : Produits importés, frais et semences livrés à Ballou.
- **Suivi de colis** : Suivi en temps réel des expéditions entre les deux zones.
- **Paiement sécurisé** : Intégration des instructions pour Wave et Orange Money.
- **Administration** : Tableau de bord pour gérer les flux et les commandes.

## Technologies
- React / TypeScript
- Tailwind CSS / Shadcn UI
- Supabase (Auth & Database)
- React Router
